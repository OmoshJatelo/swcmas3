Current state — what you built
The system currently has collectors upload a beforePhoto and afterPhoto when they start
and complete a collection. The "verification" is a mock: Math.random() * 100 determines
whether an AI "auto-verified" it. The real scoring in verifyCollection() gives 20 points to

The new detection approach
An ESP32 with an ultrasonic sensor (HC-SR04) mounts inside each bin lid and measures the
distance to the waste surface every few minutes. The system then infers collection by
detecting a significant drop in fill level (e.g. from 85% full to 12% full) within a time window
around the scheduled collection time. No human input, no photos, no fake AI.

The detection algorithm (most important part)
When completeCollection() is called:
1. Look up the latest SensorReading for this bin that was recorded before
collection.startTime

2. Look up the latest reading recorded after collection.endTime
3. Compute fillDelta = preFill - postFill
4. If fillDelta >= 60% (configurable threshold) → sensorVerified = true , sensor score
= 20
5. If delta is 30–60% → prorated score, flag for landlord review
6. If delta < 30% or no post-reading available → score = 0, trigger anomaly
